# BaoMiHua Project

爆米花 BaoMiHua 的公开构建与发布仓库。

BaoMiHua 是一款跨平台影音播放器，支持订阅资源站在线搜索、播放与下载，提供服务端（CLI）、桌面（Windows / macOS / Linux）与移动端（Android / iOS）等多种形态。

本仓库由源码仓库自动同步构建配置并发布各平台安装包（GitHub Release）：

- CLI（服务端）：Windows / macOS / Linux 多架构 + Android
- GUI（桌面应用）：Windows / macOS / Linux
- 移动端：Android APK、iOS IPA
- Linux 软件包：deb / rpm / apk / archlinux
